Δραστηριότητα CAS: Το «κιτ εργαλείων» στο Maxima

Μέσα σε μια ΣΔΕ οι παράγωγοι γράφονται με απόστροφο ('diff), ώστε να μην υπολογιστούν αμέσως.

  1. (α)Μιγαδικοί και απλά κλάσματα. Η polarform(1+%i*sqrt(3)) δίνει την εκθετική μορφή, η realpart( integrate( exp((2+3*%i)*t), t)) το Παράδειγμα 0.1 και η partfrac(R, s) τα Παραδείγματα 0.3–0.6.
  2. (β)Ολοκληρώματα. Υπολογίστε τα integrate(t\^{}3*exp(-2*t), t, 0, inf) και integrate(exp(-x\^{}2), x, minf, inf). Με declare(n, integer) και assume(n>0) υπολογίστε το $\int_{-\pi}^{\pi}x^2\cos nx\,dx$ και συγκρίνετε με το Παράδειγμα 0.10.
  3. (γ)ΣΔΕ. Λύστε το Παράδειγμα 0.16 με ode2('diff(y,t,2)-'diff(y,t)-2*y=4*t-2*exp(t), y, t) και επιβάλετε τις αρχικές συνθήκες με ic2(%, t=0, y=0, 'diff(y,t)=1). Για το Παράδειγμα 0.13 χρησιμοποιήστε την ic1.
  4. (δ)Μερικές παράγωγοι. Για το Παράδειγμα 0.18 ορίστε u: exp(-x\^{}2/(4*t))/sqrt(t) και υπολογίστε το ratsimp(diff(u,t) - diff(u,x,2)).

⬇ Λήψη .mac Στο wxMaxima: File › Batch File… ή batch("maxima_ch00.mac")$

/* =====================================================================
   Κεφάλαιο 0 — Μαθηματικό Υπόβαθρο: το «κιτ εργαλείων» στο Maxima
   Συνοδευτικός κώδικας του βιβλίου «Μετασχηματισμοί Laplace και Fourier,
   Μερικές Διαφορικές Εξισώσεις», Ν. Ματζάκος.
   Εκτέλεση: στο wxMaxima, File > Batch File… ή  batch("maxima_ch00.mac")$
   ===================================================================== */

/* ---------- Α. Μιγαδικοί αριθμοί και μιγαδική εκθετική ---------- */
z: 1 + %i*sqrt(3)$
polarform(z);                     /* εκθετική μορφή: 2*%e^(%i*%pi/3) */
rectform(2*%e^(%i*%pi/3));        /* και πίσω σε καρτεσιανή μορφή */
cabs(z);  carg(z);                /* μέτρο και όρισμα */

/* Παράδειγμα 0.1: ∫e^(2t)cos3t dt και ∫e^(2t)sin3t dt με ΜΙΑ ολοκλήρωση */
J: integrate(exp((2+3*%i)*t), t)$
Ic: ratsimp(realpart(rectform(J)));
Is: ratsimp(imagpart(rectform(J)));
/* έλεγχος με παραγώγιση: πρέπει να δώσει 0 και 0 */
ratsimp(diff(Ic,t) - exp(2*t)*cos(3*t));
ratsimp(diff(Is,t) - exp(2*t)*sin(3*t));

/* Φάσορες: 3cos(t) + 4cos(t + π/2) = A cos(t + φ) */
P: 3 + 4*%e^(%i*%pi/2)$
[cabs(P), float(carg(P))];        /* A = 5, φ ≈ 0,927 rad */

/* ---------- Β. Ανάλυση σε απλά κλάσματα (Παραδείγματα 0.3–0.7) ---------- */
partfrac((8*s-2)/(s^3+s^2-2*s), s);          /* Παράδειγμα 0.3 */
partfrac((2*s^2-s+3)/((s+1)^2*(s-2)), s);    /* Παράδειγμα 0.4 */
partfrac((s^2+4*s+1)/(s+1)^3, s);            /* Παράδειγμα 0.5 */
partfrac((s+7)/((s-1)*(s^2+2*s+5)), s);      /* Παράδειγμα 0.6 */
partfrac(6/((s^2+1)*(s^2+4)), s);            /* Παράδειγμα 0.7 */
partfrac(32/(s^4-16), s);                    /* Λυμένη Άσκηση 0.1 */

/* ---------- Γ. Γενικευμένα ολοκληρώματα ---------- */
integrate(t^3*exp(-2*t), t, 0, inf);         /* 3!/2^4 = 3/8 */
integrate(exp(-x^2), x, minf, inf);          /* sqrt(%pi) */
integrate(exp(-t)*sin(2*t), t, 0, inf);      /* 2/5 */
gamma(1/2);  gamma(5/2);                     /* sqrt(%pi), 3*sqrt(%pi)/4 */
/* Παράδειγμα 0.10(β): ολοκλήρωμα τύπου Fourier με ακέραιο n > 0 */
declare(n, integer)$  assume(n > 0)$
ratsimp(integrate((x^2+x)*cos(n*x), x, -%pi, %pi));   /* 4*%pi*(-1)^n/n^2 */
integrate(x^2*cos(n*x), x, -%pi, %pi);

/* ---------- Δ. Διαφορικές εξισώσεις ---------- */
/* Παράδειγμα 0.13: y' + y/t = 3t, y(1) = 2 */
sol1: ode2('diff(y,t) + y/t = 3*t, y, t);
ic1(sol1, t=1, y=2);
/* Παράδειγμα 0.16: y'' - y' - 2y = 4t - 2e^t, y(0) = 0, y'(0) = 1 */
gen: ode2('diff(y,t,2) - 'diff(y,t) - 2*y = 4*t - 2*exp(t), y, t);
ic2(gen, t=0, y=0, 'diff(y,t)=1);
/* Λυμένη Άσκηση 0.5: y'' + 2y' + 5y = 10cos t, y(0) = y'(0) = 0 */
gen2: ode2('diff(y,t,2) + 2*'diff(y,t) + 5*y = 10*cos(t), y, t);
ic2(gen2, t=0, y=0, 'diff(y,t)=0);

/* ---------- Ε. Μερικές παράγωγοι ---------- */
/* Παράδειγμα 0.18: η u = e^(-x^2/(4t))/sqrt(t) λύνει την u_t = u_xx */
u: exp(-x^2/(4*t))/sqrt(t)$
ratsimp(diff(u,t) - diff(u,x,2));            /* 0 */
/* Θεώρημα Schwarz: οι μικτές παράγωγοι συμπίπτουν */
v: x^2*sin(3*y) + exp(2*x-y)$
diff(v,x,1,y,1) - diff(v,y,1,x,1);           /* 0 */

Δραστηριότητα Python: Επαλήθευση με SymPy και SciPy

  1. (α)Επαληθεύστε τις αναλύσεις της Ενότητας 0.2 με την sympy.apart, π.χ. apart(32/(s**4-16), s). Τι επιστρέφει η apart για την $1/(s^2+2s+5)$ και γιατί;
  2. (β)Λύστε τη Λυμένη Άσκηση 0.5 με την dsolve(..., ics=\{y(0):0, y(t).diff(t).subs(t,0):0\}).
  3. (γ)Με n = symbols('n', integer=True, positive=True) υπολογίστε το ολοκλήρωμα του Παραδείγματος 0.10(β)· έπειτα υπολογίστε αριθμητικά το ολοκλήρωμα Gauss με scipy.integrate.quad( lambda x: np.exp(-x**2), -np.inf, np.inf).
  4. (δ)Για τις αποκρίσεις του Σχήματος 0.3 με $\zeta=0{,}7$, $0{,}85$, $1$, πότε μένει η καθεμία οριστικά κάτω από το $1\%$; Είναι η κρίσιμη απόσβεση η ταχύτερη;

⬇ Λήψη .pyΟ κώδικας τρέχει στον browser σας (Pyodide).

# =====================================================================
#  Κεφάλαιο 0 — Μαθηματικό Υπόβαθρο: επαλήθευση με SymPy και SciPy
#  Συνοδευτικός κώδικας του βιβλίου «Μετασχηματισμοί Laplace και Fourier,
#  Μερικές Διαφορικές Εξισώσεις», Ν. Ματζάκος.
#  Τρέχει όπως είναι σε Python 3 (sympy, numpy, scipy, matplotlib)
#  ή απευθείας στη σελίδα του βιβλίου (Pyodide).
# =====================================================================
import sympy as sp
import numpy as np
from scipy.integrate import quad
import matplotlib.pyplot as plt

s, t, x = sp.symbols('s t x')

# ---------- Α. Ανάλυση σε απλά κλάσματα (Ενότητα 0.2) ----------
print("Α. Απλά κλάσματα")
print("  32/(s^4-16)            =", sp.apart(32/(s**4 - 16), s))
print("  (s+7)/((s-1)(s^2+2s+5)) =", sp.apart((s + 7)/((s - 1)*(s**2 + 2*s + 5)), s))
# Ο παράγοντας s^2+2s+5 είναι ανάγωγος (ρίζες -1±2i): η apart τον αφήνει ανέπαφο.
print("  1/(s^2+2s+5)           =", sp.apart(1/(s**2 + 2*s + 5), s))

# ---------- Β. Π.Α.Τ. της Λυμένης Άσκησης 0.5 ----------
print("\nΒ. y'' + 2y' + 5y = 10cos t, y(0) = y'(0) = 0")
y = sp.Function('y')
ode = sp.Eq(y(t).diff(t, 2) + 2*y(t).diff(t) + 5*y(t), 10*sp.cos(t))
sol = sp.dsolve(ode, ics={y(0): 0, y(t).diff(t).subs(t, 0): 0})
print("  y(t) =", sp.simplify(sol.rhs))

# ---------- Γ. Ολοκληρώματα ----------
print("\nΓ. Ολοκληρώματα")
n = sp.symbols('n', integer=True, positive=True)
In = sp.integrate((x**2 + x)*sp.cos(n*x), (x, -sp.pi, sp.pi))
print("  I_n = ∫(x^2+x)cos(nx)dx στο [-π,π] =", sp.simplify(In))      # Παράδειγμα 0.10(β)
val, err = quad(lambda u: np.exp(-u**2), -np.inf, np.inf)              # ολοκλήρωμα Gauss
print(f"  ∫e^(-x^2)dx ≈ {val:.12f}   (√π = {np.sqrt(np.pi):.12f}, σφάλμα ≈ {err:.1e})")

# ---------- Δ. Απόσβεση: χρόνος αποκατάστασης 1% (Σχήμα 0.3) ----------
# y'' + 2ζy' + y = 0, y(0) = 1, y'(0) = 0  (ω0 = 1)
print("\nΔ. Χρόνος μετά τον οποίο |y(t)| < 1% οριστικά")
tt = np.linspace(0, 20, 200001)
def response(z, tt):
    if z < 1:
        wd = np.sqrt(1 - z**2)
        return np.exp(-z*tt)*(np.cos(wd*tt) + z/wd*np.sin(wd*tt))
    if z == 1:
        return (1 + tt)*np.exp(-tt)
    r1, r2 = -z + np.sqrt(z**2 - 1), -z - np.sqrt(z**2 - 1)
    return (r2*np.exp(r1*tt) - r1*np.exp(r2*tt))/(r2 - r1)

plt.figure(figsize=(7, 3.6))
for z in (0.7, 0.85, 1.0):
    yy = response(z, tt)
    ts = tt[np.nonzero(np.abs(yy) >= 0.01)[0][-1]]
    print(f"  ζ = {z:<4}: t_1% ≈ {ts:.2f}")
    plt.plot(tt, yy, label=f"ζ = {z}")
plt.axhspan(-0.01, 0.01, color='0.85')
plt.xlim(0, 12); plt.xlabel("t"); plt.ylabel("y(t)"); plt.legend(); plt.grid(alpha=.3)
plt.title("Αποκρίσεις και ζώνη ±1%")
plt.show()
