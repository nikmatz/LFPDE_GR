Δραστηριότητα CAS: Μετασχηματισμοί Laplace και ιδιότητες

Στο Maxima η εντολή laplace(f, t, s) υπολογίζει τον μετασχηματισμό της έκφρασης f. Για παραμέτρους χρειάζεται συχνά να δηλώσετε το πρόσημό τους με assume.

  1. (α)Επαληθεύστε τον Πίνακα 1.1: υπολογίστε τους μετασχηματισμούς των $t^5$, $e^{-3t}$, $\sin\omega t$, $\cos\omega t$, $\sinh 2t$ (με assume(w>0)).
  2. (β)Επαληθεύστε το πρώτο θεώρημα μετατόπισης: συγκρίνετε τα laplace(exp(a*t)*sin(t), t, s) και subst(s-a, s, laplace(sin(t), t, s)).
  3. (γ)Υπολογίστε τους $\Lap\{t\sin\omega t\}$, $\Lap\{\sin t/t\}$ και $\Lap\{\sqrt t\}$ και συγκρίνετε με τα Παραδείγματα 1.14, 1.16 και την Πρόταση 1.3.
  4. (δ)Μετασχηματίστε τη διαφορική εξίσωση της Λυμένης Άσκησης 1.7 με atvalue και laplace και λύστε ως προς τον μετασχηματισμό με solve.

/* =====================================================================
   Κεφάλαιο 1 — Ο Μετασχηματισμός Laplace: μετασχηματισμοί και ιδιότητες
   Συνοδευτικός κώδικας του βιβλίου «Μετασχηματισμοί Laplace και Fourier,
   Μερικές Διαφορικές Εξισώσεις», Ν. Ματζάκος.
   Εκτέλεση: στο wxMaxima, File > Batch File… ή  batch("maxima_ch01.mac")$
   ===================================================================== */

/* ---------- Α. Ο Πίνακας 1.1 ---------- */
assume(w > 0)$
laplace(1, t, s);
laplace(t^5, t, s);                          /* 5!/s^6 */
laplace(exp(-3*t), t, s);
laplace(cos(w*t), t, s);
laplace(sin(w*t), t, s);
laplace(sinh(2*t), t, s);
laplace(sqrt(t), t, s);                      /* Γ(3/2)/s^(3/2) = sqrt(%pi)/(2 s^(3/2)) */

/* Ο ορισμός «με το χέρι»: το ολοκλήρωμα χρειάζεται s > 0 */
assume(s > 0)$
integrate(exp(-s*t)*t, t, 0, inf);           /* 1/s^2 */
forget(s > 0)$

/* ---------- Β. Πρώτο θεώρημα μετατόπισης ---------- */
laplace(exp(a*t)*sin(t), t, s);
subst(s - a, s, laplace(sin(t), t, s));      /* το ίδιο αποτέλεσμα */
laplace(exp(-2*t)*cos(3*t), t, s);

/* ---------- Γ. Πολλαπλασιασμός και διαίρεση με t ---------- */
laplace(t*sin(w*t), t, s);                   /* Παράδειγμα 1.14 */
ratsimp(laplace(t*cos(w*t), t, s));
-diff(laplace(sin(w*t), t, s), s);           /* ίδιο με τον τύπο -F'(s) */
factor(ratsimp(laplace(t^2*cos(t), t, s)));   /* Παράδειγμα 1.15 */
/* Παράδειγμα 1.16(α): L{sin t / t} = ∫_s^∞ F(σ) dσ */
assume(s > 0)$
integrate(1/(u^2+1), u, s, inf);             /* %pi/2 - atan(s) = atan(1/s) */
forget(s > 0)$

/* ---------- Δ. Λυμένη Άσκηση 1.7: y'' - 4y' + 4y = t e^(2t), y(0)=1, y'(0)=0 ---------- */
atvalue(y(t), t=0, 1)$
atvalue(diff(y(t), t), t=0, 0)$
eq: laplace(diff(y(t),t,2) - 4*diff(y(t),t) + 4*y(t) = t*exp(2*t), t, s);
Ysol: solve(eq, laplace(y(t), t, s));
Y: rhs(Ysol[1])$
partfrac(Y, s);                              /* όροι της μορφής c/(s-2)^k */
ilt(Y, s, t);                                /* η λύση y(t) */

/* ---------- Ε. Θεωρήματα αρχικής και τελικής τιμής (Λυμένη Άσκηση 1.8) ---------- */
F: (s+4)/(s*(s+2))$
limit(s*F, s, inf);                          /* f(0+) = 1 */
limit(s*F, s, 0);                            /* lim f(t) = 2 */
ilt(F, s, t);                                /* επαλήθευση: f(t) = 2 - e^(-2t) */

Δραστηριότητα Python: Ο μετασχηματισμός με SymPy και αριθμητικός έλεγχος

  1. (α)Με τη συνάρτηση laplace_transform της SymPy υπολογίστε τους μετασχηματισμούς των Λυμένων Ασκήσεων 1.3–1.5 (χρησιμοποιήστε noconds=True).
  2. (β)Για $s=2$ υπολογίστε αριθμητικά το ολοκλήρωμα $\int_0^\infty e^{-2t}\,t\cos t\,dt$ με scipy.integrate.quad και συγκρίνετε με την ακριβή τιμή $3/25$ της Εφαρμογής 1.3.
  3. (γ)Σχεδιάστε με Matplotlib την ολοκληρωτέα συνάρτηση $e^{-st}f(t)$ για $f(t)=e^{0{,}5t}$ και $s=0{,}6,\ 1,\ 2$. Για ποιες τιμές του $s$ «σβήνει» η ουρά; Συνδέστε την παρατήρηση με το Παράδειγμα 1.3.
  4. (δ)Προαιρετικό: Γράψτε μια συνάρτηση που ελέγχει αριθμητικά το θεώρημα τελικής τιμής για τη $Y(s)$ του Παραδείγματος 1.19.

# =====================================================================
#  Κεφάλαιο 1 — Ο Μετασχηματισμός Laplace με SymPy και αριθμητικός έλεγχος
#  Συνοδευτικός κώδικας του βιβλίου «Μετασχηματισμοί Laplace και Fourier,
#  Μερικές Διαφορικές Εξισώσεις», Ν. Ματζάκος.
#  Τρέχει όπως είναι σε Python 3 (sympy, numpy, scipy, matplotlib)
#  ή απευθείας στη σελίδα του βιβλίου (Pyodide).
# =====================================================================
import sympy as sp
import numpy as np
from scipy.integrate import quad
import matplotlib.pyplot as plt

t, s = sp.symbols('t s', positive=True)

def L(f):
    """Μετασχηματισμός Laplace (χωρίς τις συνθήκες σύγκλισης), απλοποιημένος."""
    return sp.simplify(sp.laplace_transform(f, t, s, noconds=True))

# ---------- Α. Λυμένες Ασκήσεις 1.3–1.5 ----------
print("Α. Μετασχηματισμοί")
print("  L{4t²e^(-t) + 3cosh2t - 5e^(2t)sin3t} =", L(4*t**2*sp.exp(-t) + 3*sp.cosh(2*t) - 5*sp.exp(2*t)*sp.sin(3*t)))
print("  L{t e^(-2t) sin t}                  =", sp.factor(L(t*sp.exp(-2*t)*sp.sin(t))))
print("  L{sin²t / t}                        =", L(sp.sin(t)**2/t))
print("  L{√t}                               =", L(sp.sqrt(t)))

# ---------- Β. Αριθμητικός έλεγχος της Εφαρμογής 1.3(α) ----------
print("\nΒ. ∫_0^∞ e^(-2t) t cos t dt")
val, err = quad(lambda u: np.exp(-2*u)*u*np.cos(u), 0, np.inf)
print(f"  αριθμητικά ≈ {val:.12f},  ακριβής τιμή 3/25 = {3/25:.12f}")

# ---------- Γ. Πότε «σβήνει» η ουρά της e^(-st) e^(0.5t); (Παράδειγμα 1.3) ----------
tt = np.linspace(0, 12, 600)
plt.figure(figsize=(7, 3.6))
for sv in (0.6, 1.0, 2.0):
    plt.plot(tt, np.exp(-(sv - 0.5)*tt), label=f"s = {sv}")
plt.xlabel("t"); plt.ylabel("e^(-st) e^(0.5t)")
plt.title("Η ολοκληρωτέα του ορισμού για f(t) = e^(0.5t)")
plt.legend(); plt.grid(alpha=.3)
plt.show()
print("\nΓ. Για s > 0.5 η ολοκληρωτέα φθίνει εκθετικά· όσο πιο κοντά στο 0.5, τόσο πιο αργά.")

# ---------- Δ. (Προαιρετικό) θεώρημα τελικής τιμής για το Παράδειγμα 1.19 ----------
# y'' + 3y' + 2y = 0, y(0) = 1, y'(0) = 0  ->  Y(s) = (s+3)/((s+1)(s+2))
Y = (s + 3)/((s + 1)*(s + 2))
y = sp.inverse_laplace_transform(Y, s, t)
print("\nΔ. y(t) =", sp.simplify(y))
print("   lim_{s→0} sY(s) =", sp.limit(s*Y, s, 0), "  και  y(20) ≈", float(y.subs(t, 20)))
