Δραστηριότητα CAS: Σειρές Fourier με το πακέτο fourie

Μετά το load(fourie), η fourier(f,x,p) δίνει τους συντελεστές της $f$ στο $[-p,p]$, η foursimp τους απλοποιεί και η fourexpand(λίστα,x,p,N) γράφει τη μερική σειρά $S_N$. Προσοχή: το a[0] του Maxima είναι ο σταθερός όρος, δηλαδή το δικό μας $a_0/2$.

  1. (α)Επαληθεύστε το Παράδειγμα 5.8 και πάρτε την $S_3$ με τις εντολές
    totalfourier(x\^{}2+x,x,%pi);
    fourexpand(foursimp(fourier(x\^{}2+x, x,%pi)), x,%pi,3);
  2. (β)Η foursimp(fourier(abs(sin(x)), x, %pi)) δίνει $a_n$ με παρονομαστή $(n-1)(n+1)$. Τι γίνεται για $n=1$; Συγκρίνετε με την Εφαρμογή 5.2.
  3. (γ)Το fourie δεν χειρίζεται τμηματικές συναρτήσεις (δοκιμάστε signum(x)). Για το Παράδειγμα 5.9, με declare(n,integer) και assume(n>0), βρείτε το $b_n$ με integrate και δώστε τη λίστα [a[0]=1/2, a[n]=0, b[n]=bn] στην fourexpand.
  4. (δ)Πάρτε τα αναπτύγματα του Παραδείγματος 5.13 με τις fourcos(x,x,%pi) και foursin(x,x,%pi).

/* =====================================================================
   Κεφάλαιο 5 — Περιοδικές συναρτήσεις και σειρές Fourier
   Συνοδευτικός κώδικας του βιβλίου «Μετασχηματισμοί Laplace και Fourier,
   Μερικές Διαφορικές Εξισώσεις», Ν. Ματζάκος.
   Εκτέλεση: στο wxMaxima, File > Batch File… ή  batch("maxima_ch05.mac")$
   Προσοχή: στο πακέτο fourie το a[0] είναι ο σταθερός όρος, δηλαδή το a0/2 του βιβλίου.
   ===================================================================== */
load(fourie)$

/* ---------- Α. Παράδειγμα 5.8: η σειρά της x^2 + x στο (-π, π) ---------- */
totalfourier(x^2 + x, x, %pi);
fourexpand(foursimp(fourier(x^2 + x, x, %pi)), x, %pi, 3);       /* η μερική σειρά S_3 */

/* ---------- Β. Εφαρμογή 5.2: |sin x| — τι γίνεται για n = 1; ---------- */
foursimp(fourier(abs(sin(x)), x, %pi));
a1: 2*integrate(sin(x)*cos(x), x, 0, %pi)/%pi;                     /* a_1 χωριστά: 0 */

/* ---------- Γ. Παράδειγμα 5.9: σήμα δύο σταθμών, με integrate ---------- */
declare(n, integer)$  assume(n > 0)$
bn: ratsimp((integrate(-sin(n*x), x, -%pi, 0) + integrate(2*sin(n*x), x, 0, %pi))/%pi);
fourexpand([a[0] = 1/2, a[n] = 0, b[n] = bn], x, %pi, 5);

/* ---------- Δ. Παράδειγμα 5.13: δύο αναπτύγματα της x στο (0, π) ---------- */
fourcos(x, x, %pi);
foursin(x, x, %pi);

/* ---------- Ε. Παράδειγμα 5.14: ημιτονικό ανάπτυγμα της cos x ---------- */
bc: ratsimp(2/%pi*integrate(cos(x)*sin(n*x), x, 0, %pi));      /* n ≥ 2 */
makelist(ev(bc, n = k), k, 2, 8);                                   /* μόνο οι άρτιοι δείκτες */
[float(8/%pi*sum(k*sin(2*k*%pi/4)/(4*k^2 - 1), k, 1, 2000)), float(cos(%pi/4))];   /* αργή σύγκλιση */

/* ---------- ΣΤ. Παράδειγμα 5.5: ολοκληρώματα με ορθογωνιότητα ---------- */
f: -1 + 3*cos(x) + 2*sin(2*x)$
g: (2*cos(x) - sin(x))^2$
expand(trigreduce(expand(g)));                                      /* 5/2 + 3/2 cos2x - 2 sin2x */
ratsimp(integrate(f^2, x, -%pi, %pi));                              /* 15π */
ratsimp(integrate(f*g, x, -%pi, %pi));                              /* -9π */

/* ---------- Ζ. Εφαρμογή 5.1: αθροίσματα από τις σειρές ---------- */
sum(1/k^2, k, 1, inf), simpsum;
[float(sum((-1)^(k+1)/k^2, k, 1, 2000)), float(%pi^2/12)];        /* εναλλάσσουσα: π²/12 */
float(4*sum((-1)^(k+1)/(2*k - 1), k, 1, 1000));                     /* σειρά Leibniz → π */

/* ---------- Η. Φαινόμενο Gibbs (Πρόταση 5.3) ---------- */
S(N, x) := 4/%pi*sum(sin((2*k - 1)*x)/(2*k - 1), k, 1, (N + 1)/2)$
float(S(9, %pi/10));                                                /* 1,1823 */
float(S(49, %pi/50));                                               /* 1,1791 */
float(2/%pi*expintegral_si(%pi));                                   /* 1,17898 */

Δραστηριότητα Python: Μερικές σειρές και φαινόμενο Gibbs

    fourier_series(x**2+x, (x,-pi,pi)).truncate(3)
    fourier_series(Piecewise((-1,x<0),(2,True)), (x,-pi,pi)).truncate(4)
  2. (β)Με NumPy βρείτε το μέγιστο της μερικής σειράς του τετραγωνικού παλμού στο $(0,\pi/2]$ για $N=9,49,199$ (Πρόταση 5.3) και σχεδιάστε με Matplotlib το Σχήμα 5.5.

⬇ Λήψη .pyΟ κώδικας τρέχει στον browser σας (Pyodide).

# =====================================================================
#  Κεφάλαιο 5 — Σειρές Fourier με SymPy, φαινόμενο Gibbs με NumPy
#  Συνοδευτικός κώδικας του βιβλίου «Μετασχηματισμοί Laplace και Fourier,
#  Μερικές Διαφορικές Εξισώσεις», Ν. Ματζάκος.
#  Τρέχει όπως είναι σε Python 3 (sympy, numpy, scipy, matplotlib)
#  ή απευθείας στη σελίδα του βιβλίου (Pyodide).
# =====================================================================
import sympy as sp
import numpy as np
from scipy.special import sici
import matplotlib.pyplot as plt

x = sp.symbols('x', real=True)
n = sp.symbols('n', integer=True, positive=True)
pi = sp.pi

# ---------- Α. Παράδειγμα 5.8: η σειρά της x^2 + x ----------
s1 = sp.fourier_series(x**2 + x, (x, -pi, pi))
print("Α. x^2 + x  ~ ", s1.truncate(5), " + ...")
an = sp.simplify(sp.integrate((x**2 + x)*sp.cos(n*x), (x, -pi, pi))/pi)
bn = sp.simplify(sp.integrate((x**2 + x)*sp.sin(n*x), (x, -pi, pi))/pi)
print("   a_n =", an, ",   b_n =", bn)

# ---------- Β. Παράδειγμα 5.9: σήμα δύο σταθμών ----------
s2 = sp.fourier_series(sp.Piecewise((-1, x < 0), (2, True)), (x, -pi, pi))
print("\nΒ. δύο στάθμες ~ ", s2.truncate(4), " + ...")

# ---------- Γ. Παράδειγμα 5.5: ολοκληρώματα με ορθογωνιότητα ----------
f = -1 + 3*sp.cos(x) + 2*sp.sin(2*x)
g = (2*sp.cos(x) - sp.sin(x))**2
print("\nΓ. g =", sp.simplify(sp.expand(sp.fu(g))))
print("   ∫f² =", sp.integrate(f**2, (x, -pi, pi)), ",   ∫fg =", sp.integrate(f*g, (x, -pi, pi)))

# ---------- Δ. Παράδειγμα 5.14: ημιτονικό ανάπτυγμα της cos x ----------
b = [sp.integrate(2/pi*sp.cos(x)*sp.sin(k*x), (x, 0, pi)) for k in range(1, 9)]
print("\nΔ. b_1..b_8 =", b)
K = np.arange(1, 20001)
print("   άθροισμα στο x=π/4: %.5f   (cos(π/4) = %.5f)" % (8/np.pi*np.sum(K*np.sin(K*np.pi/2)/(4*K**2 - 1)), np.cos(np.pi/4)))

# ---------- Ε. Πρόταση 5.3: το φαινόμενο Gibbs ----------
xx = np.linspace(1e-6, np.pi/2, 20001)
print("\nΕ.   N    max S_N     θέση      π/(N+1)")
for N in (9, 49, 199):
    k = np.arange(1, (N + 1)//2 + 1)
    S = 4/np.pi*np.sum(np.sin(np.outer(2*k - 1, xx))/(2*k - 1)[:, None], axis=0)
    print(f"   {N:3d}   {S.max():.4f}   {xx[S.argmax()]:.5f}   {np.pi/(N + 1):.5f}")
print("   όριο (2/π)Si(π) = %.5f" % (2/np.pi*sici(np.pi)[0]))

# ---------- ΣΤ. Παράδειγμα 5.12: η πριονωτή κοντά στο π ----------
for N in (10, 50, 200):
    m = np.arange(1, N + 1)
    xN = np.pi - np.pi/(N + 1)
    print(f"ΣΤ. N = {N:3d}:  S_N(x_N) = {2*np.sum((-1.0)**(m + 1)*np.sin(m*xN)/m):.4f}")
print("    όριο 2Si(π) = %.4f" % (2*sici(np.pi)[0]))

# ---------- Ζ. Σχήμα 5.5: μερικές σειρές του τετραγωνικού παλμού ----------
X = np.linspace(-np.pi, np.pi, 1201)
plt.figure(figsize=(7, 3.6))
plt.plot(X, np.sign(X), "k", lw=2, alpha=.35, label="q(x)")
for N in (1, 3, 7, 49):
    k = np.arange(1, (N + 1)//2 + 1)
    plt.plot(X, 4/np.pi*np.sum(np.sin(np.outer(2*k - 1, X))/(2*k - 1)[:, None], axis=0), label=f"S_{N}")
plt.axhline(1.179, ls="--", c="r", lw=.8)
plt.xlabel("x"); plt.grid(alpha=.3); plt.legend(fontsize=8)
plt.show()
