Δραστηριότητα CAS: Επαλήθευση λύσεων διάχυσης

  1. (α)Η συνάρτηση σφάλματος. Επαληθεύστε τη λύση του Παραδείγματος 10.10:
    assume(k>0,t>0)\$ u:T0*erfc(x/(2*sqrt(k*t)))\$
    ratsimp(diff(u,t)-k*diff(u,x,2)); $\to0$.
    Το ίδιο για τη λύση του Παραδείγματος 10.4 και της Λυμένης Άσκησης 10.5.
  2. (β)Ζεύγη Laplace. Το Maxima αναγνωρίζει το ζεύγος (β) της Πρότασης 10.8:
    assume(a>0,s>0)\$ laplace(exp(-a\^{}2/(4*t))/sqrt(%pi*t),t,s);
    Για το (α) δίνει μια έκφραση με συναρτήσεις Bessel· ελέγξτε αριθμητικά ότι ισούται με $e^{-a\sqrt s}$.
  3. (γ)Ράβδος πεπερασμένου μήκους. Για το Παράδειγμα 10.13:
    b(n):=200*(1-(-1)\^{}n)/(%pi*n)\$
    U(x,t,N):=sum(b(m)*exp(-2*m\^{}2*t)*sin(m*x),m,1,N)\$
    float(U(%pi/2,0.467,41)); $\to50{,}03$, και σχεδιάστε την $U$ για $t=0{,}01$, $0{,}1$, $0{,}5$ με την plot2d.
  4. (δ)Πυρήνας Poisson. assume(y>0)\$ w:integrate(1/((x-z)\^{}2+y\^{}2),z,-1,1)\$
    ratsimp(rectform(logcontract(w))); δίνει τη λύση του Παραδείγματος 10.7, πολλαπλασιασμένη με $\pi/y$.

/* =====================================================================
   Κεφάλαιο 10 — Επίλυση ΜΔΕ με μετασχηματισμούς
   Συνοδευτικός κώδικας του βιβλίου «Μετασχηματισμοί Laplace και Fourier,
   Μερικές Διαφορικές Εξισώσεις», Ν. Ματζάκος.
   Εκτέλεση: στο wxMaxima, File > Batch File… ή  batch("maxima_ch10.mac")$
   ===================================================================== */
assume(k > 0, t > 0, a > 0)$

/* ---------- Α. Ο θερμικός πυρήνας (Ορισμός 10.2, Θεώρημα 10.1) ---------- */
G: exp(-x^2/(4*k*t))/sqrt(4*%pi*k*t)$
ratsimp(diff(G, t) - k*diff(G, x, 2));               /* 0: λύνει την u_t = k u_xx */
integrate(G, x, minf, inf);                          /* 1: συνολική θερμότητα */

/* ---------- Β. Γκαουσιανή αρχική θερμοκρασία (Παράδειγμα 10.2) ---------- */
u: exp(-x^2/(1 + 4*k*t))/sqrt(1 + 4*k*t)$
ratsimp(diff(u, t) - k*diff(u, x, 2));               /* 0 */
integrate(u, x, minf, inf);                          /* √π για κάθε t */

/* ---------- Γ. Λύσεις με τη συνάρτηση σφάλματος ---------- */
u: T0*erfc(x/(2*sqrt(k*t)))$                         /* Παράδειγμα 10.10 */
ratsimp(diff(u, t) - k*diff(u, x, 2));               /* 0 */
-kappa*subst(x = 0, diff(u, x));                     /* ροή κ T0/√(πkt) */
u: (erf((x + a)/(2*sqrt(k*t))) - erf((x - a)/(2*sqrt(k*t))))/2$   /* Παράδειγμα 10.4 */
ratsimp(diff(u, t) - k*diff(u, x, 2));               /* 0 */
float(subst([x = 0, k = 1, a = 1, t = 1], u));       /* ≈ 0,520 */
u: 2*q0/kappa*sqrt(k*t/%pi)*exp(-x^2/(4*k*t)) - q0*x/kappa*erfc(x/(2*sqrt(k*t)))$  /* Λυμένη Άσκηση 10.5 */
ratsimp(diff(u, t) - k*diff(u, x, 2));               /* 0 */
ratsimp(-kappa*subst(x = 0, diff(u, x)));            /* q0: σταθερή ροή στην επιφάνεια */

/* ---------- Δ. Ζεύγη Laplace με √s (Πρόταση 10.8) ---------- */
assume(s > 0)$
laplace(exp(-a^2/(4*t))/sqrt(%pi*t), t, s);          /* e^{-a√s}/√s */
/* το (α) αριθμητικά, για a = 1, s = 2 */
float(quad_qagi(1/(2*sqrt(%pi)*t^(3/2))*exp(-1/(4*t))*exp(-2*t), t, 0, inf)[1]);
float(exp(-sqrt(2)));
/* το (γ): L{erfc(a/(2√t))} = e^{-a√s}/s, αριθμητικά */
float(quad_qagi(erfc(1/(2*sqrt(t)))*exp(-2*t), t, 0, inf)[1]);
float(exp(-sqrt(2))/2);

/* ---------- Ε. Ο πυρήνας του Duhamel (Θεώρημα 10.4, Παράδειγμα 10.12) ---------- */
K: x/(2*sqrt(%pi*k)*t^(3/2))*exp(-x^2/(4*k*t))$
ratsimp(diff(K, t) - k*diff(K, x, 2));               /* 0 */
solve(diff(log(K), t) = 0, t);                       /* t* = x²/(6k) */

/* ---------- ΣΤ. Ράβδος πεπερασμένου μήκους (Παράδειγμα 10.13) ---------- */
b(n) := 200*(1 - (-1)^n)/(%pi*n)$
U(x, t, N) := sum(b(m)*exp(-2*m^2*t)*sin(m*x), m, 1, N)$
float(U(%pi/2, 0.467, 41));                          /* ≈ 50,03 */
float(log(8/%pi)/2);                                 /* t ≈ 0,467 από τον πρώτο όρο */
plot2d([U(x, 0.01, 41), U(x, 0.1, 41), U(x, 0.5, 41)], [x, 0, %pi],
       [legend, "t = 0,01", "t = 0,1", "t = 0,5"])$

/* ---------- Ζ. Πυρήνας Poisson (Παράδειγμα 10.7) ---------- */
assume(y > 0)$
w: integrate(1/((x - z)^2 + y^2), z, -1, 1)$
ratsimp(rectform(logcontract(w)));                   /* (atan((x+1)/y) - atan((x-1)/y))/y */
P: y/(%pi*(x^2 + y^2))$
ratsimp(diff(P, x, 2) + diff(P, y, 2));              /* 0: ο πυρήνας είναι αρμονικός */
integrate(P, x, minf, inf);                          /* 1 */

/* ---------- Η. Πρόταση 10.4: πηγή θερμότητας (Παράδειγμα 10.5, k = 1) ---------- */
ua: integrate(exp(-(t - s))*cos(x), s, 0, t);  /* (1 − e^{−t}) cos x */
ratsimp(diff(ua, t) - diff(ua, x, 2) - cos(x));  /* 0 */
assume(t > 0)$
integrate(1/sqrt(4*%pi*(t - s)), s, 0, t);     /* u(0,t) = √(t/π) */

Δραστηριότητα Python: Η εξίσωση θερμότητας με τον ταχύ μετασχηματισμό Fourier

Ο ταχύς μετασχηματισμός Fourier (FFT) του Κεφαλαίου 6 υλοποιεί αριθμητικά τη μέθοδο του κεφαλαίου: μετασχηματίζουμε, πολλαπλασιάζουμε με $e^{-k\omega^2t}$ και αντιστρέφουμε.

  1. (α)Σε ένα πλέγμα $N=1024$ σημείων στο $[-20,20)$ ορίστε τον ορθογώνιο παλμό του Παραδείγματος 10.4 ($a=1$, $k=1$) και υπολογίστε
    w = 2*np.pi*np.fft.fftfreq(N, d=dx)
    u = np.fft.ifft(np.fft.fft(f)*np.exp(-k*w**2*t)).real
    για $t=0{,}05$, $0{,}25$ και $1$. Συγκρίνετε με τον τύπο της $\erf$ (scipy.special.erf). Γιατί η μέθοδος «βλέπει» μια περιοδική ράβδο μήκους $40$ και πότε αυτό αλλοιώνει τη λύση;
  2. (β)Για τη ράβδο του Παραδείγματος 10.13, βρείτε πόσοι όροι της σειράς χρειάζονται ώστε η θερμοκρασία στο μέσο να υπολογίζεται με σφάλμα μικρότερο από $1$ βαθμό τις στιγμές $t=0{,}001$, $0{,}01$ και $0{,}1$. Εξηγήστε το αποτέλεσμα με τους παράγοντες $e^{-2n^2t}$.
  3. (γ)Για την πλάκα του Παραδείγματος 10.16 ($a=1$, $T_0=100$) υπολογίστε τη μερική σειρά σε πλέγμα $201\times201$ σημείων (np.meshgrid) και σχεδιάστε τις ισοθερμικές καμπύλες με την plt.contour, όπως στο Σχήμα 10.6. Γράψτε τον λόγο $\frac{\sinh n\pi y}{\sinh n\pi}$ ως
    np.exp(n*np.pi*(y-1))*(1-np.exp(-2*n*np.pi*y))/(1-np.exp(-2*n*np.pi)).
    Γιατί ο απλός τύπος np.sinh(n*np.pi*y)/np.sinh(n*np.pi) αποτυγχάνει για μεγάλα $n$;

# =====================================================================
#  Κεφάλαιο 10 — Η εξίσωση θερμότητας: FFT, συνάρτηση σφάλματος, σειρές
#  Συνοδευτικός κώδικας του βιβλίου «Μετασχηματισμοί Laplace και Fourier,
#  Μερικές Διαφορικές Εξισώσεις», Ν. Ματζάκος.
#  Τρέχει όπως είναι σε Python 3 (sympy, numpy, scipy, matplotlib)
#  ή απευθείας στη σελίδα του βιβλίου (Pyodide).
# =====================================================================
import numpy as np
import sympy as sp
from scipy.special import erf, erfc
import matplotlib.pyplot as plt

# ---------- Α. Επαλήθευση λύσεων με τη SymPy ----------
x, t, k, T0, a = sp.symbols('x t k T_0 a', positive=True)
for name, u in [("θερμικός πυρήνας", sp.exp(-x**2/(4*k*t))/sp.sqrt(4*sp.pi*k*t)),
                ("Παράδειγμα 10.10", T0*sp.erfc(x/(2*sp.sqrt(k*t)))),
                ("Παράδειγμα 10.4", (sp.erf((x + a)/(2*sp.sqrt(k*t))) - sp.erf((x - a)/(2*sp.sqrt(k*t))))/2)]:
    print(f"Α. {name:18s}: u_t - k u_xx =", sp.simplify(u.diff(t) - k*u.diff(x, 2)))

# ---------- Β. Η μέθοδος του κεφαλαίου με FFT (Παράδειγμα 10.4, a = k = 1) ----------
# μετασχηματίζουμε, πολλαπλασιάζουμε με e^{-kω²t}, αντιστρέφουμε
N, Lbox, kk = 1024, 40.0, 1.0
xs = -Lbox/2 + Lbox*np.arange(N)/N               # πλέγμα στο [-20, 20)
dx = xs[1] - xs[0]
# ο παλμός ως μέση τιμή σε κάθε κελί: τα άκρα ±1 δεν είναι κόμβοι του πλέγματος
f = np.clip((np.minimum(xs + dx/2, 1) - np.maximum(xs - dx/2, -1))/dx, 0, 1)
w = 2*np.pi*np.fft.fftfreq(N, d=dx)
exact = lambda X, T: 0.5*(erf((X + 1)/(2*np.sqrt(kk*T))) - erf((X - 1)/(2*np.sqrt(kk*T))))
heat = lambda T: np.fft.ifft(np.fft.fft(f)*np.exp(-kk*w**2*T)).real
print("\nΒ. FFT έναντι του τύπου της erf")
plt.figure(figsize=(7, 3.4))
plt.plot(xs, f, "k--", lw=1, label="t = 0")
for T in (0.05, 0.25, 1.0, 100.0):
    u = heat(T)
    print(f"   t = {T:6.2f}:  u(0,t) = {u[N//2]:.5f}  (τύπος {exact(0.0, T):.5f}),"
          f"  μέγιστο σφάλμα {np.abs(u - exact(xs, T)).max():.1e}")
    if T <= 1: plt.plot(xs, u, label=f"t = {T}")
plt.xlim(-5, 5); plt.xlabel("x"); plt.legend(fontsize=8); plt.grid(alpha=.3)
plt.title("Διάχυση του ορθογώνιου παλμού με FFT"); plt.show()
print("   Για t = 100 η FFT «βλέπει» περιοδική ράβδο μήκους 40: τα είδωλα του παλμού")
print("   ανεβάζουν τη θερμοκρασία προς τη μέση τιμή 2/40 = 0,05.")

# ---------- Γ. Ημιάπειρη ράβδος (Παράδειγμα 10.10): η κλίμακα √(kt) ----------
print("\nΓ. Βάθος όπου u = T0/2, δηλαδή erfc(η) = 1/2 με η ≈ 0,4769:")
for T in (1, 4, 16):
    print(f"   t = {T:2}: x = 2·0,4769·√(kt) = {2*0.4769*np.sqrt(kk*T):.3f}")
print("   τετραπλάσιος χρόνος ⇒ διπλάσιο βάθος")

# ---------- Δ. Ράβδος πεπερασμένου μήκους (Παράδειγμα 10.13): πόσοι όροι; ----------
def mid_temp(T, nmax):
    n = np.arange(1, nmax + 1, 2, dtype=float)  # μόνο περιττά n (float: στο Pyodide οι ακέραιοι είναι 32 bit)
    return 400/np.pi*np.sum(np.exp(-2*n**2*T)/n*np.sin(n*np.pi/2))
print("\nΔ. Θερμοκρασία στο μέσο της ράβδου")
for T in (0.001, 0.01, 0.1, 0.467):
    ref = mid_temp(T, 200001)
    nmax = next(m for m in range(1, 200001, 2) if abs(mid_temp(T, m) - ref) < 1)
    terms = "αρκεί ο όρος n = 1" if nmax == 1 else f"αρκούν οι όροι n = 1, 3, …, {nmax} ({(nmax + 1)//2} όροι)"
    print(f"   t = {T:5}: u(π/2,t) = {ref:7.3f};  για σφάλμα < 1 βαθμό {terms}")
print("   Οι παράγοντες e^{-2n²t} σβήνουν γρήγορα τους υψηλούς όρους μόνο όταν το t δεν είναι πολύ μικρό.")

# ---------- Ε. Ο πυρήνας του Duhamel: πότε φτάνει ο θερμικός παλμός (Παράδειγμα 10.12) ----------
kc, xd = 5e-7, 0.1                              # δομικό υλικό, βάθος 10 cm
Ts = np.linspace(1, 20000, 200001)
K = xd/(2*np.sqrt(np.pi*kc)*Ts**1.5)*np.exp(-xd**2/(4*kc*Ts))
print(f"\nΕ. μέγιστο του K στο t = {Ts[np.argmax(K)]:.0f} s  (τύπος x²/(6k) = {xd**2/(6*kc):.0f} s)")

# ---------- ΣΤ. Πρόταση 10.4: πηγή θερμότητας (Παράδειγμα 10.5) ----------
x_, t_, s_ = sp.symbols('x t s', real=True)
ua = sp.integrate(sp.exp(-(t_ - s_))*sp.cos(x_), (s_, 0, t_))              # Q = cos x, k = 1
print("Q = cos x:  u =", sp.simplify(ua), "  έλεγχος:", sp.simplify(ua.diff(t_) - ua.diff(x_, 2) - sp.cos(x_)))
tp = sp.symbols('t', positive=True)
u0 = sp.integrate(1/sp.sqrt(4*sp.pi*(tp - s_)), (s_, 0, tp))               # Q = δ(x): θερμοκρασία στην πηγή
print("Q = δ(x):  u(0,t) =", sp.simplify(u0))

# ---------- Ζ. Τετραγωνική πλάκα (Παράδειγμα 10.16): ισοθερμικές καμπύλες ----------
X, Y = np.meshgrid(np.linspace(0, 1, 201), np.linspace(0, 1, 201))   # a = 1, T0 = 100
U = np.zeros_like(X)
for m in np.arange(1, 400, 2, dtype=float):                         # περιττά n
    ratio = np.exp(m*np.pi*(Y - 1))*(1 - np.exp(-2*m*np.pi*Y))/(1 - np.exp(-2*m*np.pi))
    U += 400/np.pi*ratio*np.sin(m*np.pi*X)/m
print(f"\nΖ. Θερμοκρασία στο κέντρο: {U[100, 100]:.4f}  (ακριβής τιμή T0/4 = 25)")
plt.figure(); cs = plt.contour(X, Y, U, levels=[5, 10, 25, 50, 75]); plt.clabel(cs, fmt='%d')
plt.gca().set_aspect('equal'); plt.title("Ισοθερμικές καμπύλες της πλάκας"); plt.show()
with np.errstate(over='ignore', invalid='ignore'):
    naive = np.sinh(301*np.pi*1.0)/np.sinh(301*np.pi)                # στο y = 1 θα έπρεπε να είναι 1
print("   απλός τύπος sinh(nπy)/sinh(nπ) για n = 301, y = 1:", naive, "(υπερχείλιση: inf/inf)")
