Δραστηριότητα CAS: Ο τύπος του d'Alembert και οι συντελεστές της χορδής

  1. (α)Επαλήθευση του τύπου. Για το Παράδειγμα 9.6:
    f(x):=x\^{}2\$ g(x):=cos(x)\$ c:3\$
    u:(f(x-c*t)+f(x+c*t))/2+integrate(g(s),s,x-c*t,x+c*t)/(2*c)\$
    trigsimp(trigexpand(u)); και ratsimp(diff(u,t,2)-c\^{}2*diff(u,x,2)); $\to0$.
    Επαναλάβετε με $f(x)=e^{-x^2}$, $g(x)=2c\,x\,e^{-x^2}$ (Παράδειγμα 9.7).
  2. (β)Συντελεστές Fourier. Για την τραβηγμένη χορδή του Παραδείγματος 9.13:
    declare(n,integer)\$ assume(L>0)\$
    A:2/L*(integrate(3*h/L*x*sin(n*%pi*x/L),x,0,L/3)
    +integrate(3*h/(2*L)*(L-x)*sin(n*%pi*x/L),x,L/3,L))\$
    ratsimp(A); $\to\frac{9h}{\pi^2n^2}\sin\frac{\pi n}{3}$.
  3. (γ)Στιγμιότυπα. Με $L=h=c=1$ σχεδιάστε το άθροισμα $30$ όρων τις στιγμές $t=0,\frac13,\frac23,1$ με την plot2d και συγκρίνετε με το Σχήμα 9.8.
  4. (δ)Ενέργεια. Με w:n*%pi*sqrt(T/rho)/L\$ και τον κανονικό τρόπο
    un:sin(n*%pi*x/L)*(a*cos(w*t)+b*sin(w*t))\$
    υπολογίστε την $E(t)$ του Ορισμού 9.4 με την integrate και δείξτε με την trigsimp ότι δεν εξαρτάται από το $t$ (Πρόταση 9.6).

/* =====================================================================
   Κεφάλαιο 9 — Η κυματική εξίσωση και η μέθοδος d'Alembert
   Συνοδευτικός κώδικας του βιβλίου «Μετασχηματισμοί Laplace και Fourier,
   Μερικές Διαφορικές Εξισώσεις», Ν. Ματζάκος.
   Εκτέλεση: στο wxMaxima, File > Batch File… ή  batch("maxima_ch09.mac")$
   ===================================================================== */

/* ---------- Α. Ο τύπος του d'Alembert (Παράδειγμα 9.6) ---------- */
dalembert(f, g, c) := (f(x - c*t) + f(x + c*t))/2 + integrate(g(s), s, x - c*t, x + c*t)/(2*c)$
f(x) := x^2$  g(x) := cos(x)$
u: dalembert(f, g, 3)$
trigsimp(trigexpand(u));                       /* x² + 9t² + (1/3) cos x sin 3t */
ratsimp(diff(u, t, 2) - 9*diff(u, x, 2));      /* 0: λύνει την u_tt = 9 u_xx */
[subst(t = 0, u), subst(t = 0, diff(u, t))];   /* οι αρχικές συνθήκες [x², cos x] */

/* ---------- Β. Κύμα μίας κατεύθυνσης (Παράδειγμα 9.7) ---------- */
kill(f, g)$  assume(c > 0)$
f(x) := exp(-x^2)$  g(x) := 2*c*x*exp(-x^2)$
u: dalembert(f, g, c)$
ratsimp(u);                                    /* e^{-(x-ct)²}: μόνο το κύμα προς τα δεξιά */

/* ---------- Γ. Υπερβολική εξίσωση με τη μέθοδο d'Alembert (Παράδειγμα 9.8) ---------- */
/* ρίζες της C λ² - 2B λ + A = 0 και λύση της μορφής Φ(x - λ1 y) + Ψ(x - λ2 y) */
gradef(Phi(s), Phi1(s))$  gradef(Phi1(s), Phi2(s))$
gradef(Psi(s), Psi1(s))$  gradef(Psi1(s), Psi2(s))$
solve(l^2 + l - 2 = 0, l);                     /* για την 2u_xx + u_xy - u_yy: λ = 1, -2 */
w: Phi(x - y) + Psi(x + 2*y)$
ratsimp(2*diff(w, x, 2) + diff(w, x, 1, y, 1) - diff(w, y, 2));          /* 0 */
u: 2/3*cos(x - y) + 1/3*cos(x + 2*y) + 3*x^2*y + 3*x*y^2 + 3*y^3$
ratsimp(2*diff(u, x, 2) + diff(u, x, 1, y, 1) - diff(u, y, 2));          /* 0 */
[subst(y = 0, u), subst(y = 0, diff(u, y))];   /* [cos x, 3x²] */

/* ---------- Δ. Συντελεστές της τραβηγμένης χορδής (Παράδειγμα 9.13) ---------- */
declare(n, integer)$  assume(L > 0)$
A: 2/L*(integrate(3*h/L*x*sin(n*%pi*x/L), x, 0, L/3)
      + integrate(3*h/(2*L)*(L - x)*sin(n*%pi*x/L), x, L/3, L))$
ratsimp(A);                                    /* 9h/(π² n²) sin(πn/3) */
makelist(ratsimp(subst(n = k, A)), k, 1, 6);   /* η 3η και η 6η αρμονική λείπουν */

/* ---------- Ε. Στιγμιότυπα με L = h = c = 1 (Σχήμα 9.8) ---------- */
U(x, t, N) := sum(9/(%pi^2*m^2)*sin(%pi*m/3)*sin(m*%pi*x)*cos(m*%pi*t), m, 1, N)$
plot2d([U(x, 0, 30), U(x, 1/3, 30), U(x, 2/3, 30), U(x, 1, 30)], [x, 0, 1],
       [legend, "t = 0", "t = 1/3", "t = 2/3", "t = 1"])$

/* ---------- ΣΤ. Ενέργεια κανονικών τρόπων (Πρόταση 9.6) ---------- */
assume(rho > 0, T > 0)$
cc: sqrt(T/rho)$  om: n*%pi*cc/L$
un: sin(n*%pi*x/L)*(a*cos(om*t) + b*sin(om*t))$
E: ratsimp(trigsimp(integrate(rho*diff(un, t)^2 + T*diff(un, x)^2, x, 0, L)/2))$
ratsimp(E - rho*L/4*om^2*(a^2 + b^2));         /* 0: η ενέργεια δεν εξαρτάται από το t */

/* ---------- Ζ. Θεώρημα 9.3: η μη ομογενής κυματική εξίσωση (Παράδειγμα 9.10, c = 1) ---------- */
assume(t > 0)$
duh(F) := ratsimp(integrate(integrate(F, s, x - (t - tau), x + (t - tau)), tau, 0, t)/2)$
duh(s);                                        /* x t²/2 */
ub: ratsimp(trigexpand(duh(sin(s)*sin(tau)))); /* (sin t − t cos t) sin x / 2 */
ratsimp(trigexpand(diff(ub, t, 2) - diff(ub, x, 2) - sin(x)*sin(t)));   /* 0 */

Δραστηριότητα Python: Αριθμητική λύση με πεπερασμένες διαφορές

Χωρίζουμε το $[0,L]$ σε κόμβους $x_j=j\,\Delta x$ και τον χρόνο σε βήματα $t_m=m\,\Delta t$, και αντικαθιστούμε τις δεύτερες παραγώγους με κεντρικές διαφορές: \[ u_j^{m+1}=2u_j^m-u_j^{m-1}+r^2\bigl(u_{j+1}^m-2u_j^m+u_{j-1}^m\bigr),\qquad r=\frac{c\,\Delta t}{\Delta x}. \]

  1. (α)Υλοποιήστε το σχήμα με τη NumPy για την τραβηγμένη χορδή του Παραδείγματος 9.13 (για το πρώτο βήμα: $u_j^1=u_j^0+\frac{r^2}{2}(u_{j+1}^0-2u_j^0+u_{j-1}^0)$, αφού $g=0$) και συγκρίνετε με τη σειρά Fourier τη στιγμή $t=L/c$.
  2. (β)Τρέξτε με $r=0{,}9$, $r=1$ και $r=1{,}05$. Για $r=1$ η αριθμητική λύση συμπίπτει με την ακριβή στους κόμβους, ενώ για $r>1$ «εκρήγνυται». Είναι η συνθήκη CFL (Courant–Friedrichs–Lewy): το αριθμητικό χωρίο εξάρτησης πρέπει να περιέχει το φυσικό χωρίο εξάρτησης της Ενότητας 9.4.
  3. (γ)Με $\rho=T=1$ υπολογίστε σε κάθε βήμα τη διακριτή ενέργεια \[ E^m=\frac{\Delta x}{2}\sum_j\Bigl[\Bigl(\frac{u_j^{m+1}-u_j^m}{\Delta t}\Bigr)^2+\Bigl(\frac{u_{j+1}^m-u_j^m}{\Delta x}\Bigr)^2\Bigr]. \] Για $r\le1$ μένει κοντά στην τιμή $\frac{9Th^2}{4L}$ του Παραδείγματος 9.15, ενώ για $r>1$ αυξάνεται εκθετικά.

# =====================================================================
#  Κεφάλαιο 9 — Η κυματική εξίσωση: d'Alembert, σειρές Fourier και
#  πεπερασμένες διαφορές
#  Συνοδευτικός κώδικας του βιβλίου «Μετασχηματισμοί Laplace και Fourier,
#  Μερικές Διαφορικές Εξισώσεις», Ν. Ματζάκος.
#  Τρέχει όπως είναι σε Python 3 (sympy, numpy, matplotlib)
#  ή απευθείας στη σελίδα του βιβλίου (Pyodide).
# =====================================================================
import sympy as sp
import numpy as np
import matplotlib.pyplot as plt

# ---------- Α. Ο τύπος του d'Alembert με τη SymPy (Παράδειγμα 9.6) ----------
x, t, s = sp.symbols('x t s', real=True)
c = 3
f = lambda z: z**2
g = lambda z: sp.cos(z)
u = (f(x - c*t) + f(x + c*t))/2 + sp.integrate(g(s), (s, x - c*t, x + c*t))/(2*c)
print("Α. u(x,t) =", sp.simplify(sp.expand_trig(u)))
print("   u_tt - 9 u_xx =", sp.simplify(u.diff(t, 2) - c**2*u.diff(x, 2)),
      "  u(x,0) =", u.subs(t, 0), "  u_t(x,0) =", sp.simplify(u.diff(t).subs(t, 0)))

# ---------- Β. Η τραβηγμένη χορδή (Παράδειγμα 9.13), L = h = c = 1 ----------
L = h = cc = 1.0
def f0(xx):                       # τραβηγμένη στο x = L/3 σε ύψος h
    return np.where(xx < L/3, 3*h*xx/L, 3*h*(L - xx)/(2*L))
def series(xx, tt, N=200):
    n = np.arange(1, N + 1)[:, None]
    A = 9*h/(np.pi**2*n**2)*np.sin(np.pi*n/3)
    return np.sum(A*np.sin(n*np.pi*xx/L)*np.cos(n*np.pi*cc*tt/L), axis=0)
print("\nΒ. A_n για n = 1..6:", np.round([9/(np.pi**2*k**2)*np.sin(np.pi*k/3) for k in range(1, 7)], 4),
      " (η 3η και η 6η λείπουν)")

# ---------- Γ. Πεπερασμένες διαφορές και συνθήκη CFL ----------
def fd(r, J=90, T_end=1.0):
    """Σχήμα u_j^{m+1} = 2u_j^m - u_j^{m-1} + r²(u_{j+1}^m - 2u_j^m + u_{j-1}^m)."""
    xs = np.linspace(0, L, J + 1); dx = L/J; dt = r*dx/cc
    M = int(round(T_end/dt))                  # u1 = u^1, οπότε χρειάζονται M - 1 βήματα
    u0 = f0(xs); u1 = u0.copy()
    u1[1:-1] = u0[1:-1] + r**2/2*(u0[2:] - 2*u0[1:-1] + u0[:-2])       # g = 0
    E = []
    for m in range(M - 1):
        u2 = np.zeros_like(u1)
        u2[1:-1] = 2*u1[1:-1] - u0[1:-1] + r**2*(u1[2:] - 2*u1[1:-1] + u1[:-2])
        # διακριτή ενέργεια με ρ = T = 1 (Ορισμός 9.4)
        E.append(dx/2*(np.sum(((u2 - u1)/dt)**2) + np.sum((np.diff(u1)/dx)**2)))
        u0, u1 = u1, u2
        if np.abs(u1).max() > 1e6: break
    return xs, u1, (m + 2)*dt, np.array(E)

print("\nΓ. Τη στιγμή t = L/c η ακριβής λύση είναι -f(L-x) (Παράδειγμα 9.13)· ακριβής ενέργεια E = 2,25")
for r in (0.9, 1.0, 1.05):
    xs, uh, tt, E = fd(r)
    if abs(tt - 1) < 1e-9:
        print(f"   r = {r:4}:  σφάλμα από την ακριβή {np.abs(uh + f0(L - xs)).max():.1e},"
              f"  από τη σειρά (2000 όροι) {np.abs(uh - series(xs, tt, 2000)).max():.1e},"
              f"  E μεταξύ {E.min():.3f} και {E.max():.3f}")
    else:
        print(f"   r = {r:4}:  «έκρηξη» τη στιγμή t = {tt:.2f}: max|u| = {np.abs(uh).max():.1e}, E = {E[-1]:.1e}")

# ---------- Δ. Στιγμιότυπα (Σχήμα 9.8) ----------
xx = np.linspace(0, L, 601)
plt.figure(figsize=(7, 3.4))
for tt, sty in zip((0, 1/3, 2/3, 1), ("-", "--", "-.", ":")):
    plt.plot(xx, series(xx, tt), sty, label=f"t = {tt:.2f}")
plt.axhline(0, c="k", lw=.5); plt.xlabel("x"); plt.legend(fontsize=8); plt.grid(alpha=.3)
plt.title("Τραβηγμένη χορδή: άθροισμα 200 όρων"); plt.show()

# ---------- Ε. Ενέργεια ανά κανονικό τρόπο (Πρόταση 9.6, Λυμένη Άσκηση 9.5) ----------
n = np.arange(1, 4001)
En = (np.sin(np.pi*n/3)/n)**2                 # ∝ n² A_n² για την τραβηγμένη χορδή
print("\nΕ. ποσοστό ενέργειας στις 3 πρώτες αρμονικές:", np.round(100*En[:3]/En.sum(), 1), "%")

# ---------- ΣΤ. Θεώρημα 9.3: η μη ομογενής κυματική εξίσωση (Παράδειγμα 9.10) ----------
x_, t_, s_, tau_ = sp.symbols('x t s tau', real=True)
def duhamel(F, c=1):
    """(1/2c) ∫_0^t ∫_{x-c(t-τ)}^{x+c(t-τ)} F(s,τ) ds dτ, με F γραμμένη στις μεταβλητές s, tau."""
    inner = sp.integrate(F, (s_, x_ - c*(t_ - tau_), x_ + c*(t_ - tau_)))
    return sp.simplify(sp.integrate(inner, (tau_, 0, t_))/(2*c))

for F in (s_, sp.sin(s_)*sp.sin(tau_)):
    u = duhamel(F)
    print("F =", F, " ->  u =", u, "  έλεγχος:", sp.simplify(u.diff(t_, 2) - u.diff(x_, 2) - F.subs({s_: x_, tau_: t_})))
