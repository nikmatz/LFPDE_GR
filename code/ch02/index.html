Δραστηριότητα CAS: Βηματικές συναρτήσεις, δέλτα και περιοδικά σήματα

\sloppy Στο Maxima η βηματική συνάρτηση γράφεται unit_step(t-a) και η δέλτα delta(t-a). Η εντολή laplace τις χειρίζεται σωστά, ενώ η ilt δεν αντιστρέφει όρους με $e^{-as}$· τότε αντιστρέφουμε τον $F(s)$ και κάνουμε «με το χέρι» την καθυστέρηση.

  1. (α)Επαληθεύστε το Παράδειγμα 2.5(α) και το συνηθισμένο λάθος, συγκρίνοντας τα laplace(unit_step(t-2)*t\^{}2, t, s) και laplace(unit_step(t-2)*(t-2)\^{}2, t, s).
  2. (β)Υπολογίστε τους μετασχηματισμούς του τριγωνικού και του τραπεζοειδούς παλμού (Παράδειγμα 2.8) και παραγοντοποιήστε τους με factor. Το Maxima γράφει το αποτέλεσμα με δυνάμεις του $e^{s}$· μετατρέψτε το στη μορφή του βιβλίου.
  3. (γ)Υπολογίστε τα laplace(delta(t-3), t, s) και laplace(exp(-t)*delta(t-1), t, s).
  4. (δ)Δοκιμάστε την ilt(exp(-s)*2/(s\^{}2+4), s, t): το Maxima επιστρέφει την έκφραση ανεπεξέργαστη. Βρείτε την κίνηση της Εφαρμογής 2.2 με g: ilt(2/(s\^{}2+4), s, t) και subst(t-1, t, g)*unit_step(t-1) και σχεδιάστε τη με plot2d.
  5. (ε)Για περιοδικές συναρτήσεις εφαρμόστε το Θεώρημα 2.4 απευθείας: με assume(s>0) υπολογίστε το integrate(t*exp(-s*t), t, 0, 2)/(1-exp(-2*s)) και συγκρίνετε με το Παράδειγμα 2.16 για $T=2$.

/* =====================================================================
   Κεφάλαιο 2 — Βηματικές συναρτήσεις, συνάρτηση Dirac και περιοδικά σήματα
   Συνοδευτικός κώδικας του βιβλίου «Μετασχηματισμοί Laplace και Fourier,
   Μερικές Διαφορικές Εξισώσεις», Ν. Ματζάκος.
   Εκτέλεση: στο wxMaxima, File > Batch File… ή  batch("maxima_ch02.mac")$
   ===================================================================== */

/* ---------- Α. Πρακτική μορφή και το «συνηθισμένο λάθος» (Παράδειγμα 2.5(α)) ---------- */
/* Σωστό: L{u(t-2) t^2} = e^(-2s) L{(t+2)^2} = e^(-2s) (2/s^3 + 4/s^2 + 4/s)            */
expand(laplace(unit_step(t-2)*t^2, t, s));
/* Η καθυστέρηση της t^2 είναι άλλη συνάρτηση: L{u(t-2)(t-2)^2} = 2 e^(-2s)/s^3.
   Το «συνηθισμένο λάθος» δίνει αυτό το αποτέλεσμα και για την u(t-2) t^2.               */
laplace(unit_step(t-2)*(t-2)^2, t, s);

/* ---------- Β. Τριγωνικός και τραπεζοειδής παλμός (Παράδειγμα 2.8) ---------- */
tri: t - 2*(t-1)*unit_step(t-1) + (t-2)*unit_step(t-2)$
factor(laplace(tri, t, s));        /* e^(-2s)(e^s-1)^2/s^2 = (1-e^(-s))^2/s^2 */
trap: t - (t-1)*unit_step(t-1) - (t-2)*unit_step(t-2) + (t-3)*unit_step(t-3)$
factor(laplace(trap, t, s));       /* = (1-e^(-s))(1-e^(-2s))/s^2 */
/* Στη μορφή του βιβλίου: πολλαπλασιάζουμε αριθμητή και παρονομαστή με e^(-3s) */
ratsimp(laplace(trap, t, s) - (1-exp(-s))*(1-exp(-2*s))/s^2);   /* 0 */

/* ---------- Γ. Η δέλτα (Θεώρημα 2.2, Παράδειγμα 2.11) ---------- */
laplace(delta(t-3), t, s);                  /* e^(-3s) */
laplace(exp(-t)*delta(t-1), t, s);          /* e^(-1) e^(-s) */
laplace(3*delta(t) - 2*delta(t-4) + cos(%pi*t)*delta(t-1), t, s);   /* 3 - 2e^(-4s) - e^(-s) */

/* ---------- Δ. Εφαρμογή 2.2: 2y'' + 8y = 0,4 δ(t-1), y(0)=y'(0)=0 ---------- */
ilt(exp(-s)*2/(s^2+4), s, t);               /* το Maxima την επιστρέφει ανεπεξέργαστη */
/* Y(s) = 0,2 e^(-s)/(s^2+4) = 0,1 e^(-s) 2/(s^2+4): αντιστρέφουμε χωρίς τον εκθετικό
   παράγοντα και κάνουμε την καθυστέρηση «με το χέρι» (Πρόταση 2.3)                      */
g: ilt(2/(s^2+4), s, t);                    /* sin(2t) */
y: 1/10*subst(t-1, t, g)*unit_step(t-1);    /* y(t) = 0,1 sin 2(t-1) u(t-1) */
plot2d(y, [t, 0, 8], [ylabel, "y(t)"])$

/* ---------- Ε. Περιοδικές συναρτήσεις (Θεώρημα 2.4, Παράδειγμα 2.16) ---------- */
assume(s > 0)$
Fsaw: integrate(t*exp(-s*t), t, 0, 2)/(1 - exp(-2*s))$   /* πριονωτό κύμα, T = 2 */
ratsimp(Fsaw);
/* Ο τύπος του βιβλίου: F = 1/s^2 - T e^(-Ts)/(s(1-e^(-Ts))) με T = 2 */
ratsimp(Fsaw - (1/s^2 - 2*exp(-2*s)/(s*(1-exp(-2*s)))));   /* 0 */
/* Μέση τιμή (Πρόταση 2.6): lim s F(s) καθώς s -> 0+ */
limit(s*Fsaw, s, 0, plus);                                 /* 1 = T/2 */
forget(s > 0)$

Δραστηριότητα Python: Βηματικές, δέλτα και αριθμητικός έλεγχος

\sloppy

  1. (α)Με τις sympy.Heaviside, sympy.DiracDelta και τη laplace_transform επαληθεύστε τα Παραδείγματα 2.7 και 2.11. Σε αντίθεση με το Maxima, η inverse_laplace_transform της SymPy αντιστρέφει και όρους με $e^{-as}$: δοκιμάστε την στη Λυμένη Άσκηση 2.3.
  2. (β)Παγίδα: δηλώστε t = symbols('t', positive=True) και υπολογίστε τον μετασχηματισμό της DiracDelta(t). Η SymPy επιστρέφει $0$! Επαναλάβετε με t = symbols('t') και εξηγήστε τη διαφορά με τη σύμβαση του κάτω ορίου $0^-$ (Θεώρημα 2.2).
  3. (γ)Σχεδιάστε με NumPy και Matplotlib τα σήματα του Σχήματος 2.5, με numpy.mod(t, T) για την περιοδική επανάληψη και numpy.heaviside(t-a, 1) για τις βηματικές.
  4. (δ)Ελέγξτε αριθμητικά τον τύπο του πριονωτού κύματος: υπολογίστε με scipy.integrate.quad το $\int_0^{40}e^{-st}f(t)\,dt$ για $T=2$ και $s=1{,}3$, δηλώνοντας τα σημεία ασυνέχειας με points=numpy.arange(2, 40, 2) και limit=200, και συγκρίνετε με το Παράδειγμα 2.16.

# =====================================================================
#  Κεφάλαιο 2 — Βηματικές, δέλτα και αριθμητικός έλεγχος
#  Συνοδευτικός κώδικας του βιβλίου «Μετασχηματισμοί Laplace και Fourier,
#  Μερικές Διαφορικές Εξισώσεις», Ν. Ματζάκος.
#  Τρέχει όπως είναι σε Python 3 (sympy, numpy, scipy, matplotlib)
#  ή απευθείας στη σελίδα του βιβλίου (Pyodide).
# =====================================================================
import sympy as sp
import numpy as np
from scipy.integrate import quad
import matplotlib.pyplot as plt

t, s = sp.symbols('t s', positive=True)
H, D = sp.Heaviside, sp.DiracDelta

def L(f):
    """Μετασχηματισμός Laplace (χωρίς τις συνθήκες σύγκλισης)."""
    return sp.laplace_transform(f, t, s, noconds=True)

# ---------- Α. Παράδειγμα 2.7: μετασχηματισμοί χωρίς ολοκληρώματα ----------
print("Α. Παράδειγμα 2.7")
signals = [("(α) κλιμακωτή τάση     ", 2 + 3*H(t-1) - 2*H(t-3) - 3*H(t-4)),
           ("(β) ράμπα με κορεσμό   ", t - (t-2)*H(t-2)),
           ("(γ) σήμα του ελεγκτή   ", 2*t - 2*(t-1)*H(t-1) - 2*H(t-3))]
for name, f in signals:
    print(" ", name, "F(s) =", sp.expand(L(f)))

# ---------- Β. Παράδειγμα 2.11: ιδιότητα επιλογής ----------
print("\nΒ. Παράδειγμα 2.11")
print("  (α) ∫(t³+1)δ(t-2)dt        =", sp.integrate((t**3 + 1)*D(t - 2), (t, 0, sp.oo)))
print("  (β) ∫e^(-3t) sin t δ(t-π/2)dt =", sp.integrate(sp.exp(-3*t)*sp.sin(t)*D(t - sp.pi/2), (t, 0, sp.oo)))
print("  (γ) L{e^(-t) δ(t-1)}       =", L(sp.exp(-t)*D(t - 1)))

# ---------- Γ. Αντιστροφή με καθυστέρηση: Λυμένη Άσκηση 2.3 ----------
F = 4*(sp.exp(-s) - sp.exp(-3*s))/(s*(s + 2))
f = sp.inverse_laplace_transform(F, s, t)
print("\nΓ. Λυμένη Άσκηση 2.3: f(t) =", f)
for tv in (0.5, 2, 4):
    print(f"   f({tv}) = {float(f.subs(t, tv)):.6f}")

# ---------- Δ. Η «παγίδα» της δέλτα στο t = 0 ----------
print("\nΔ. L{δ(t)} με t θετικό :", L(D(t)))          # 0: το t = 0 θεωρείται εκτός πεδίου
tr = sp.symbols('t')                                  # χωρίς υπόθεση για το πρόσημο
print("   L{δ(t)} με t πραγματικό:", sp.laplace_transform(D(tr), tr, s, noconds=True))
print("   Παράδειγμα 2.11(δ):", sp.laplace_transform(3*D(tr) - 2*D(tr - 4) + sp.cos(sp.pi*tr)*D(tr - 1), tr, s, noconds=True))

# ---------- Ε. Περιοδικά σήματα του Σχήματος 2.5 με NumPy ----------
x = np.linspace(0, 8, 4001)
square = np.where(np.mod(x, 2) < 1, 1.0, -1.0)            # τετραγωνικό ±1, a = 1
pwm = 1.0*(np.mod(x, 2) < 0.5)                            # PWM: V = 1, T = 2, D = 1/4
saw = np.mod(x, 2)                                        # πριονωτό, T = 2
half = np.maximum(np.sin(np.pi*x/2), 0)                   # ημιανορθωμένο ημίτονο
pulse = np.heaviside(x - 1, 1) - np.heaviside(x - 3, 1)   # ένας παλμός με βηματικές
fig, ax = plt.subplots(2, 2, figsize=(8, 5))
for a_, y_, ttl in [(ax[0, 0], square, "τετραγωνικό ±1"), (ax[0, 1], pwm, "παλμοσειρά PWM"),
                    (ax[1, 0], saw, "πριονωτό"), (ax[1, 1], half, "ημιανορθωμένο ημίτονο")]:
    a_.plot(x, y_); a_.set_title(ttl); a_.grid(alpha=.3)
ax[0, 1].plot(x, pulse, "--", label="u(t-1) - u(t-3)"); ax[0, 1].legend(loc="upper right")
plt.tight_layout()
plt.show()

# ---------- ΣΤ. Αριθμητικός έλεγχος του πριονωτού κύματος (Παράδειγμα 2.16) ----------
T, sv = 2.0, 1.3
val, err = quad(lambda u: np.exp(-sv*u)*np.mod(u, T), 0, 40, points=np.arange(2, 40, 2), limit=200)
exact = 1/sv**2 - T*np.exp(-T*sv)/(sv*(1 - np.exp(-T*sv)))
print(f"\nΣΤ. ∫_0^40 e^(-st) f(t) dt ≈ {val:.10f}")
print(f"    τύπος του βιβλίου     = {exact:.10f}   (διαφορά {abs(val - exact):.1e})")
