Δραστηριότητα CAS: Π.Α.Τ., συστήματα και κρουστικές διεγέρσεις

\raggedright Οι αρχικές συνθήκες δηλώνονται πριν από τον μετασχηματισμό με την atvalue, π.χ. atvalue(diff(y(t),t), t=0, -1).

  1. (α)Για το Παράδειγμα 4.2 ορίστε eq: diff(y(t),t,2)+4*diff(y(t),t)+3*y(t)=8*exp(t) και εκτελέστε L: laplace(eq, t, s), Ys: solve(L, laplace(y(t),t,s)), Y: rhs(Ys[1]), partfrac(Y, s) και ilt(Y, s, t). Η desolve(eq, y(t)) κάνει όλα τα βήματα μαζί· επαληθεύστε με αυτήν και τα Παραδείγματα 4.3–4.6.
  2. (β)Η desolve λύνει και συστήματα: με atvalue για τα $x$, $y$, η εντολή desolve([e1, e2], [x(t), y(t)]) λύνει το Παράδειγμα 4.15.
  3. (γ)Στο Παράδειγμα 4.11 (με 3*delta(t-1)) η desolve επιστρέφει μη υπολογισμένο ilt(…), γιατί η ilt δεν χειρίζεται τον παράγοντα $e^{-s}$. Εφαρμόστε το δεύτερο θεώρημα μετατόπισης «με το χέρι»: g: ilt(3/((s+1)\^{}2+9), s, t) και subst(t-1, t, g)*unit_step(t-1).
  4. (δ)Για το Θεώρημα 4.2, με assume(t>0) υπολογίστε το integrate(exp(-x)*sin(2*x)/2*20*cos(t-x), x, 0, t) και δείξτε με ratsimp ότι συμπίπτει με τη λύση του Παραδείγματος 4.4.

/* =====================================================================
   Κεφάλαιο 4 — Π.Α.Τ., συστήματα και κρουστικές διεγέρσεις
   Συνοδευτικός κώδικας του βιβλίου «Μετασχηματισμοί Laplace και Fourier,
   Μερικές Διαφορικές Εξισώσεις», Ν. Ματζάκος.
   Εκτέλεση: στο wxMaxima, File > Batch File… ή  batch("maxima_ch04.mac")$
   Οι αρχικές συνθήκες δηλώνονται ΠΡΙΝ από τον μετασχηματισμό με την atvalue.
   ===================================================================== */

/* ---------- Α. Παράδειγμα 4.2 βήμα–βήμα: y'' + 4y' + 3y = 8e^t, y(0)=1, y'(0)=-1 ---------- */
atvalue(y(t), t=0, 1)$
atvalue(diff(y(t), t), t=0, -1)$
eq: diff(y(t), t, 2) + 4*diff(y(t), t) + 3*y(t) = 8*exp(t)$
L: laplace(eq, t, s);                         /* 1ο βήμα: μετασχηματισμός */
Ys: solve(L, laplace(y(t), t, s));            /* 2ο βήμα: αλγεβρική επίλυση */
Y: rhs(Ys[1])$
partfrac(Y, s);                               /* απλά κλάσματα */
ilt(Y, s, t);                                 /* 3ο βήμα: y = e^t - e^(-t) + e^(-3t) */
desolve(eq, y(t));                            /* όλα τα βήματα μαζί */
kill(y)$

/* ---------- Β. Παραδείγματα 4.3–4.6 με την desolve ---------- */
atvalue(y(t), t=0, 1)$  atvalue(diff(y(t), t), t=0, 0)$
desolve(diff(y(t),t,2) + 4*diff(y(t),t) + 4*y(t) = 8*t, y(t));          /* Παράδειγμα 4.3 */
kill(y)$
atvalue(y(t), t=0, 0)$  atvalue(diff(y(t), t), t=0, 0)$
desolve(diff(y(t),t,2) + 2*diff(y(t),t) + 5*y(t) = 20*cos(t), y(t));    /* Παράδειγμα 4.4 */
kill(y)$
atvalue(y(t), t=0, 1)$  atvalue(diff(y(t), t), t=0, 2)$  atvalue(diff(y(t), t, 2), t=0, -4)$
desolve(diff(y(t),t,3) + diff(y(t),t,2) + 4*diff(y(t),t) + 4*y(t) = 10*exp(t), y(t));   /* Παράδειγμα 4.5 */
kill(y)$
atvalue(y(t), t=0, 0)$  atvalue(diff(y(t), t), t=0, 0)$
desolve(diff(y(t),t,2) - 2*diff(y(t),t) - 3*y(t) = 16*exp(3*t), y(t));  /* Παράδειγμα 4.6 */
kill(y)$

/* ---------- Γ. Σύστημα ΣΔΕ (Παράδειγμα 4.15) ---------- */
atvalue(x(t), t=0, 0)$  atvalue(y(t), t=0, 2)$
e1: diff(x(t),t) + diff(y(t),t) + 2*x(t) + 3*y(t) = 0$
e2: 2*diff(x(t),t) + diff(y(t),t) + x(t) - y(t) = 0$
desolve([e1, e2], [x(t), y(t)]);
kill(x, y)$

/* ---------- Δ. Κρουστική διέγερση (Παράδειγμα 4.11): y'' + 2y' + 10y = 3δ(t-1), y(0)=1, y'(0)=-1 ---------- */
atvalue(y(t), t=0, 1)$  atvalue(diff(y(t), t), t=0, -1)$
desolve(diff(y(t),t,2) + 2*diff(y(t),t) + 10*y(t) = 3*delta(t-1), y(t));  /* μένει ανεπεξέργαστο ilt(...) */
kill(y)$
/* Y(s) = (s+1)/((s+1)^2+9) + 3 e^(-s)/((s+1)^2+9): καθυστέρηση «με το χέρι» */
y0: ilt((s+1)/((s+1)^2+9), s, t)$             /* απόκριση μηδενικής εισόδου: e^(-t) cos 3t */
g: ilt(3/((s+1)^2+9), s, t)$                  /* e^(-t) sin 3t */
ysol: y0 + subst(t-1, t, g)*unit_step(t-1);
plot2d(ysol, [t, 0, 6], [ylabel, "y(t)"])$

/* ---------- Ε. Η απόκριση ως συνέλιξη (Θεώρημα 4.2, Παράδειγμα 4.4) ---------- */
/* h(t) = L^{-1}{1/(s^2+2s+5)} = e^(-t) sin(2t)/2 και f(t) = 20 cos t */
assume(t > 0)$
yconv: integrate(exp(-x)*sin(2*x)/2*20*cos(t-x), x, 0, t)$
atvalue(y(t), t=0, 0)$  atvalue(diff(y(t), t), t=0, 0)$
ydes: rhs(desolve(diff(y(t),t,2) + 2*diff(y(t),t) + 5*y(t) = 20*cos(t), y(t)))$
ratsimp(trigsimp(yconv - ydes));              /* 0 */
forget(t > 0)$  kill(y)$

Δραστηριότητα Python: Π.Α.Τ. με SymPy και αποκρίσεις με SciPy

  2. (β)Λύστε το Παράδειγμα 4.8 με dsolve και διέγερση 8*(Heaviside(t)-Heaviside(t-pi/2))· η SymPy επιστρέφει έναν τύπο με $\cos^2t$ — δείξτε ότι συμπίπτει με τη λύση του κειμένου.
  3. (γ)Ορίστε το σύστημα του Παραδείγματος 4.12 με sys = signal.lti([1], [1, 2, 5]). Με signal.step και signal.impulse σχεδιάστε τη βηματική και την κρουστική απόκριση· συγκρίνετε το μέγιστο της πρώτης με το $\bigl(1+e^{-\pi/2}\bigr)/5$.
  4. (δ)Με signal.lsim(sys, U=20*np.cos(t), T=t) λύστε αριθμητικά το Παράδειγμα 4.4 και βρείτε το σφάλμα.
  5. (ε)Αναπαραγάγετε το Σχήμα 4.4 με signal.lti([1],[1,2*z,1]) και ελέγξτε αριθμητικά την υπερύψωση της Πρότασης 4.4.

# =====================================================================
#  Κεφάλαιο 4 — Π.Α.Τ. με SymPy και αποκρίσεις με SciPy
#  Συνοδευτικός κώδικας του βιβλίου «Μετασχηματισμοί Laplace και Fourier,
#  Μερικές Διαφορικές Εξισώσεις», Ν. Ματζάκος.
#  Τρέχει όπως είναι σε Python 3 (sympy, numpy, scipy, matplotlib)
#  ή απευθείας στη σελίδα του βιβλίου (Pyodide).
# =====================================================================
import sympy as sp
import numpy as np
from scipy import signal
import matplotlib.pyplot as plt

t, s = sp.symbols('t s', positive=True)
y = sp.Function('y')

# ---------- Α. Παράδειγμα 4.2: y'' + 4y' + 3y = 8e^t, y(0) = 1, y'(0) = -1 ----------
ode = sp.Eq(y(t).diff(t, 2) + 4*y(t).diff(t) + 3*y(t), 8*sp.exp(t))
sol = sp.dsolve(ode, y(t), ics={y(0): 1, y(t).diff(t).subs(t, 0): -1})
print("Α. dsolve:          ", sol.rhs)
# Βήμα–βήμα: (s²Y - s + 1) + 4(sY - 1) + 3Y = 8/(s-1)
Y = sp.symbols('Y')
Ys = sp.solve(sp.Eq((s**2*Y - s + 1) + 4*(s*Y - 1) + 3*Y, 8/(s - 1)), Y)[0]
print("   Y(s) =", sp.factor(Ys), " =", sp.apart(Ys, s))
# (όρο προς όρο μετά την apart: ασφαλές και με την παλαιότερη SymPy του browser)
print("   y(t) =", sp.expand(sum(sp.inverse_laplace_transform(q, s, t) for q in sp.Add.make_args(sp.apart(Ys, s)))))

# ---------- Β. Παράδειγμα 4.8: ορθογώνιος παλμός ----------
f = 8*(sp.Heaviside(t) - sp.Heaviside(t - sp.pi/2))
sol = sp.dsolve(sp.Eq(y(t).diff(t, 2) + 4*y(t), f), y(t), ics={y(0): 0, y(t).diff(t).subs(t, 0): 0})
print("\nΒ. dsolve:", sp.simplify(sol.rhs))
book = sp.Piecewise((4*sp.sin(t)**2, t < sp.pi/2), (-4*sp.cos(2*t), True))   # η λύση του κειμένου
err = max(abs(float((sol.rhs - book).subs(t, float(tv)))) for tv in np.linspace(0.05, 9, 60))
print("   μέγιστη διαφορά από τη λύση του βιβλίου:", f"{err:.1e}")

# ---------- Γ. Παράδειγμα 4.12: H(s) = 1/(s² + 2s + 5) ----------
sys = signal.lti([1], [1, 2, 5])
tt = np.linspace(0, 8, 2001)
_, ys = signal.step(sys, T=tt)
_, h = signal.impulse(sys, T=tt)
print(f"\nΓ. max βηματικής ≈ {ys.max():.6f},  (1 + e^(-π/2))/5 = {(1 + np.exp(-np.pi/2))/5:.6f}")
print(f"   χρόνος κορυφής ≈ {tt[ys.argmax()]:.4f},  π/2 = {np.pi/2:.4f}")
plt.figure(figsize=(7, 3.6))
plt.plot(tt, ys, label="βηματική απόκριση"); plt.plot(tt, h, label="κρουστική απόκριση")
plt.axhline(0.2, ls="--", c="gray", lw=1); plt.xlabel("t"); plt.grid(alpha=.3); plt.legend()
plt.show()

# ---------- Δ. Παράδειγμα 4.4 αριθμητικά: y'' + 2y' + 5y = 20 cos t ----------
_, ynum, _ = signal.lsim(sys, U=20*np.cos(tt), T=tt)
yex = np.exp(-tt)*(-3*np.sin(2*tt) - 4*np.cos(2*tt)) + 2*np.sin(tt) + 4*np.cos(tt)
print(f"\nΔ. lsim: μέγιστο σφάλμα ως προς την ακριβή λύση = {np.abs(ynum - yex).max():.1e}")

# ---------- Ε. Σχήμα 4.4 και υπερύψωση (Πρόταση 4.4) ----------
plt.figure(figsize=(7, 3.6))
print("\nΕ.   ζ    Mp αριθμητικά   e^(-ζπ/√(1-ζ²))")
for z in (0.2, 0.5, 1.0, 2.0):
    tz, yz = signal.step(signal.lti([1], [1, 2*z, 1]), T=np.linspace(0, 14, 3001))
    plt.plot(tz, yz, label=f"ζ = {z}")
    if z < 1:
        print(f"    {z:.1f}   {yz.max() - 1:.6f}        {np.exp(-z*np.pi/np.sqrt(1 - z*z)):.6f}")
plt.axhline(1, ls="--", c="gray", lw=1); plt.xlabel("ω_n t"); plt.grid(alpha=.3); plt.legend()
plt.show()
